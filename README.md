# StudySync — A Collaborative Study Platform for Students

This repository contains everything you need to run the StudySync app locally.

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in `.env.local` if you want AI quiz generation to work.
3. Run the app:
   `npm run dev`

## Local App URL

Open: `http://localhost:3000`
